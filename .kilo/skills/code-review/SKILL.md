# Порядок работы

1. Посмотреть изменения перед мержем.
2. Проверить обязательное по чек-листу.
3. Оформить результат по формату ниже.

# Формат результата

- Только замечания, без вердикта.
- Список; каждое замечание — с указанием `файл:строка`.

# Чек-лист

Обязательно проверить:

- [ ] Логика и граничные случаи
- [ ] Безопасность

Грубые ошибки:

- Отклонение от спеки
- Сломанная логика
- Уязвимость

# Чего делать не надо

- Не переписывать код за автора — только указывать проблемы.
- Не править тесты и пороги ради зелёного CI.
- Не коммитить, не пушить, не мержить — только ревью.
- Не лезть в чужой скоуп — не выходить за рамки изменённого кода.
